Harmony Studio – קבצי האתר להעלאה לדומיין
=============================================

1. לחלץ את ה-zip ולהעלות את כל מה שבתוכו לתיקייה הראשית של הדומיין
   (public_html / www / root). הקובץ index.html צריך להיות בשורש.
2. אתר סטטי: HTML, CSS, JS, תמונות וסרטונים. אין צורך בשרת, מסד נתונים או PHP.
3. חובה HTTPS (מדיניות הפרטיות כותבת שהתעבורה מוצפנת).

חשוב: האתר כרגע חסום למנועי חיפוש (גרסת הדגמה). כדי שיופיע בגוגל צריך להסיר את החסימה בשלושה מקומות:
  א. בכל קובץ HTML למחוק את השורה:
       <meta name="robots" content="noindex,nofollow">
  ב. בקובץ _headers למחוק את השורה:  X-Robots-Tag: noindex, nofollow
     (הקובץ עובד רק ב-Netlify וב-Cloudflare. בשרת אחר אפשר להתעלם ממנו או למחוק אותו.)
  ג. בקובץ robots.txt להחליף את "Disallow: /" ב-"Allow: /"

לאחר שהדומיין ידוע: לעדכן את כתובת האתר, השם המשפטי, הכתובת והמייל בדפים
המשפטיים (terms / privacy / accessibility). כרגע מופיע בהם רק הטלפון.

הדפים המשפטיים הם טיוטה לבדיקה של עורך דין.
